# skynet-ui

A modular user interface for the Skynet Defense platform, providing dashboards, reusable components, data visualizations, feature modules, and static assets.

## Project Structure

```
skynet-ui/
├── README.md          # Project documentation
├── dashboard/         # Dashboard pages and layouts
├── components/        # Reusable UI components
├── visualizations/    # Data visualization widgets and charts
├── modules/           # Feature modules and business logic
└── assets/            # Static assets (images, fonts, styles)
```

## Getting Started

Clone the repository and navigate into the project directory:

```bash
git clone https://github.com/skynet-defense/skynet-ui.git
cd skynet-ui
```

## Directory Overview

- **dashboard/** – Top-level dashboard pages that compose components and visualizations into full-page layouts.
- **components/** – Shared, reusable UI components (buttons, forms, modals, etc.) used across the application.
- **visualizations/** – Chart and graph widgets that render telemetry, sensor data, and analytics.
- **modules/** – Self-contained feature modules encapsulating their own logic, state, and sub-components.
- **assets/** – Static files such as images, icon sets, fonts, and global stylesheets.
